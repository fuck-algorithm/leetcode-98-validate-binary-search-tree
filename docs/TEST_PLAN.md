# 测试计划

## 单元测试
- 输入解析：合法层序数组、null、空输入、根 null、空 token、非整数、范围和节点数边界。
- 树工具：构造、深度/节点数、稳定布局节点、边、序列化与随机数据合法性。
- 后续阻断项：动画状态/图例/指标/时长、稳定 frame IDs 和 anchor 引用、D3 keyed 渲染及淡出清理。

## 浏览器验收
Chromium 下测量 1920×1080 与 1366×768；覆盖外链、输入/样例/随机、四语言与持久化、步骤同步、键盘、拖拽进度、画布平移缩放、思路弹窗、多解法分支、二维码、倍速记忆、GitHub Star 与颜色约束。

运行：`npm run test:unit`、`npm run test:coverage`、`npm run test:e2e`。
